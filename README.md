# Convex Optimisation and Support Vector Machines

This repository contains implementations developed for a university coursework assignment on
convex optimisation and its application to maximum-margin classification.

The project is divided into two main parts:
1. The development of Newton-based solvers for unconstrained, equality-constrained, and
   inequality-constrained convex optimisation problems.
2. The application of these solvers to train hard-margin and soft-margin support vector machines (SVMs).

All optimisation algorithms are implemented from first principles using basic linear algebra
operations, without calling off-the-shelf optimisation routines.
